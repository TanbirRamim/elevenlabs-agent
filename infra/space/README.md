# Shadow API

Backend for [Shadow](https://shadow-web-meow-4acb.vercel.app): the Fastify API (HTTP + WebSocket)
and Microsoft Presidio (analyzer, anonymizer, image redactor) in one container. Presidio is only
reachable from inside the container; the API on port 7860 is the only public endpoint.

- Health: `GET /health`
- Session stream: `wss://<this-space>.hf.space/sessions/<id>/stream`

Source, Dockerfile and setup steps: `infra/space/` and `docs/DEPLOY_SPACE.md` in
[TanbirRamim/elevenlabs-agent](https://github.com/TanbirRamim/elevenlabs-agent).
This Space repo is generated by `infra/space/deploy.sh`; do not edit it by hand.
