# Architecture decision records

The initial decisions (1–8) are summarized in `docs/IMPLEMENTATION_PLAN.md` §3.1.
Any new decision that changes a contract, a model, a dependency category or the deployment
gets its own file here, `NNNN-short-title.md`, using this template:

```markdown
# NNNN: Title
Date: YYYY-MM-DD · Owner: Tanbir / Harshit · Status: accepted

## Context
What forced a decision (with numbers if measured).

## Decision
What we do.

## Consequences
What gets easier, what gets harder, what we'll watch.
```
